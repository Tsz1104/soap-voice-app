# 音声入力SOAPノート (Speech-to-SOAP Notes)

ブラウザの **Web Speech API** を利用した音声認識と、キーワードベースの自然言語ルールによる **SOAPノート自動分類** を行うWebアプリケーションです。

---

## 🌟 主な機能

1. **リアルタイム音声認識**
   - 「録音開始」ボタンをクリックして話しかけると、ブラウザの Web Speech API によりリアルタイムに日本語がテキスト化されます。
   - 録音中はマイクの波形アニメーションとステータスバッジ（録音中🔴）が表示されます。
   - 途切れのない継続認識（continuous recognition）に対応。

2. **テキスト編集・修正**
   - 「録音停止」ボタンを押すと、認識されたテキスト全体が確定表示されます。
   - 音声認識されたテキストはテキストエリア内で自由にキーボード手動編集が可能です。
   - サンプル文章読み込みボタンで、マイクがない環境でもすぐに動作を確認できます。

3. **キーワードベースのSOAP自動分類**
   - 「SOAP変換」ボタンをクリックすると、入力された文章を文単位に自動分割し、指定されたキーワード規則に基づいて各セクションへ振り分けます。
   - 分類された理由（一致したキーワードタグ）が各文にバッジ表示されます。

4. **モダン＆レスポンシブデザイン**
   - 白を基調とした清潔感のある医療・リハビリ向けクリーンデザイン。
   - SOAP各セクションを視認性の高い4色＋未分類カードで表示：
     - **S（主観的情報 - Subjective）**：ブルー 🔵
     - **O（客観的情報 - Objective）**：グリーン 🟢
     - **A（評価 - Assessment）**：イエロー／アンバー 🟡
     - **P（計画 - Plan）**：レッド 🔴
     - **未分類**：スレートグレー ⚪
   - スマートフォン・タブレット・PC全対応のレスポンシブレイアウト。

5. **ワンクリックコピー機能**
   - 電子カルテ等への貼り付け用に、綺麗にフォーマットされたSOAP全体の全文コピーが可能。
   - 各セクション（S, O, A, P）ごとの個別コピーボタンも搭載。

## 📋 SOAP振り分けキーワードルール

| セクション | 概要 | 主な対応キーワード |
| :--- | :--- | :--- |
| **S（主観的情報）** | 患者の自覚症状・訴え・不安・感情 | 痛い, つらい, しびれる, だるい, 動かしにくい, 不安, 眠れない, 訴え, 違和感, 苦しい, 疲れる, 気分 等 |
| **O（客観的情報）** | 検査値・測定値・バイタル・身体所見 | ROM, MMT, 度, cm, kg, mmHg, 回, 秒, 歩行, 握力, バイタル, 腫脹, 熱感, 発赤, 血圧, 脈拍, 体温, SpO2 等 |
| **A（評価）** | 分析・判断・原因考察・リスク評価 | 考えられる, 原因, 問題, 改善, 低下, 制限, リスク, 評価, 疑い, 影響, 要因, 困難, 可能性, 考察 等 |
| **P（計画）** | 治療方針・目標・介入内容・指導 | プログラム, 目標, 実施, 継続, 指導, 週, 回, セット, 退院, 自主トレ, 予定, 方針, 処方, 訓練, アプローチ 等 |
| **未分類** | 上記キーワードを含まない文 | - |

## 🚀 起動方法

### 方法1: バッチファイルを実行（推奨）
プロジェクトフォルダ内の `start.bat` をダブルクリックします。
- Pythonがインストールされている場合は、ローカルWebサーバー（`http://localhost:8000`）を自動起動してブラウザが開きます。
- Pythonがない場合でも、デフォルトブラウザで直接 `index.html` が開きます。

### 方法2: 直接ブラウザで開く
`index.html` をダブルクリックして、Google Chrome または Microsoft Edge で開いてください。

### 方法3: コマンドラインから起動する場合
PowerShellまたはコマンドプロンプトで以下を実行：
```powershell
cd C:\Users\tsz11\.gemini\antigravity\scratch\soap-notes-app
python -m http.server 8000
```
ブラウザで `http://localhost:8000` にアクセスしてください。

## 💡 ご利用にあたってのヒント
- **推奨ブラウザ**: Google Chrome、Microsoft Edge、Safari（最新版）
- **マイクの許可**: 初回起動時にブラウザから「マイクへのアクセスを許可しますか？」と表示された場合は「許可」を選択してください。
- **Web Speech API の特性**: Web Speech API（Google Chrome/Edge）は音声をクラウドで高精度に認識するため、インターネット接続が必要です。
